# 컨트롤러 구현 체크리스트

- **역할 제한**: 컨트롤러는 요청 인자 검증(`@Valid`)과 뷰/데이터 반환 타입 변환만 담당하며, 절대 비즈니스 로직을 포함하지 않는다.
- **파라미터 검증**: 저장/수정 요청 본문(`*RequestDTO`)에는 반드시 `@Valid`를 선언한다.
- **예외 처리**: 컨트롤러 내부에서 `try-catch` 블록으로 예외를 직접 포착하여 정상 응답으로 변환하지 않는다. 예외는 무조건 상위로 던져 전역 핸들러(`@RestControllerAdvice`)가 처리하도록 한다.
