# AI 페어 프로그래밍 개발 가이드 (Prompt Guide)

AI와 함께 개발(페어 프로그래밍)을 진행할 때, 각 개발 단계별로 AI에게 복사/붙여넣기하여 지시하면 가장 효율적인 프롬프트 모음입니다.
이 가이드대로 지시하시면 AI가 문서 갱신과 프로젝트 룰을 알아서 지키며 작업합니다.

---

## 1. 스캐폴드로 신규 8개 파일을 생성한 직후

> **상황**: 스캐폴드를 통해 Controller부터 HTML, JS까지 기본 뼈대를 한 번에 뽑아낸 직후

```text
방금 스캐폴드를 이용해 [ 예: 캠페인 관리 ] 신규 화면용 8개 파일을 생성했어.
해당 파일들을 읽고 다음 3가지만 최우선으로 진행해 줘.

1. **바인딩 및 로직 점검**: HTML의 Grid 컬럼과 검색 조건이 Controller/XML 파라미터와 제대로 매핑되었는지 확인하고, 추가로 구현해야 할 비즈니스 로직(저장, 삭제 분기 처리 등)을 파악해서 알려줘.
2. **문서 동기화**: docs/api-mapping.md와 docs/menu-structure.md에 방금 추가된 화면의 URI 매핑과 화면 컬럼 구조를 업데이트해 줘.
3. **핸드오프 스냅샷**: 파악된 '세부 비즈니스 로직 작업'을 HANDOFF.md에 '- [ ]' 체크리스트 형태로 요약해 줘.
```

---

## 2. 개발자가 손으로 직접 뼈대를 코딩했을 때 (수동 코딩 후 확장)

> **상황**: 스캐폴드를 안 쓰고, 개발자가 직접 Controller나 빈 HTML 파일을 수동으로 만든 뒤 AI에게 살을 붙이라고 할 때

```text
내가 방금 [ 예: /system/message ] 경로로 쓰일 Controller와 빈 HTML 파일을 손으로 직접 만들었어.
이 화면은 [ 예: 카카오 알림톡 템플릿을 등록하고 조회하는 ] 용도야. 다음 작업을 진행해 줘.

1. **코드 완성**: .claude/rules/project.md 규격에 맞춰 Service, Mapper, XML, VO를 전부 생성하고 기본 CRUD 비즈니스 로직을 연결해 줘.
2. **프론트엔드 연결**: HTML과 JS 파일에 docs/개발가이드.md 를 참고해서 TuiGrid와 조회 검색조건 뼈대를 붙여 줘.
3. **문서 동기화**: 작업이 완료되면 docs/api-mapping.md와 docs/menu-structure.md를 반드시 갱신해 줘.
```

---

## 3. 에러/버그가 발생하여 수정을 지시할 때

> **상황**: 콘솔에 에러가 나거나 UI가 깨질 때 (로그만 던지지 않고 룰을 지키도록 강제함)

```text
지금 [ 예: 부서 관리 화면에서 삭제 버튼을 누를 때 ] 아래와 같은 에러 로그가 발생했어.

[여기에 에러 로그 복사/붙여넣기]

CLAUDE.md 규칙에 따라 에러를 대충 try-catch로 삼키거나 우회하지 말고, 근본 원인을 파악해 줘. 
수정해야 할 파일이 무엇인지 원인을 먼저 설명해 주면, 내가 확인한 뒤에 코드 수정을 허락할게.
```

---

## 4. 작업(토큰)이 끝나가거나 잠시 작업을 중단할 때

> **상황**: 아직 기능이 100% 완성되지 않았는데 세션을 끄거나 다른 업무를 봐야 할 때

```text
지금 진행하던 작업은 잠시 여기서 멈출게.
지금까지 완료된 소스코드 상태를 요약하고, 다음 세션에서 켜자마자 이어서 해야 할 미완성 작업(남은 API, 남은 UI 등)을 구체적으로 정리해서 HANDOFF.md 의 '현재 작업 목표' 체크리스트에 업데이트해 줘.
```
