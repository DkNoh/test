## 1. 공통 JS 유틸리티 (`common-utils.js`)

> **위치:** `src/main/resources/static/js/common/common-utils.js`  
> 모든 페이지에서 `CommonUtils.*` 로 접근 가능 (defaultLayout.html에서 전역 로드)

### 6-1. `CommonUtils.initAutocomplete` — 자동완성(Typeahead)

텍스트 입력 시 DB를 조회해 말풍선 형태의 후보 목록을 표시하는 공통 기능.

```javascript
CommonUtils.initAutocomplete({
    inputEl:   '#bankCdText',           // 텍스트 input (selector 또는 Element)
    balloonEl: '#bankBalloon',          // 말풍선 container div
    apiUrl:    '/api/common-code/bank', // 검색 API — ?keyword=xxx 자동 추가
    syncCombo: '#bankCdCombo',          // 연동 콤보박스 (선택 시 동기화, 생략 가능)
    paramName:  'keyword',              // 쿼리 파라미터명 (기본값: keyword)
    minLength:  1,                      // 최소 입력 글자 수 (기본값: 1)
    debounceMs: 200,                    // 디바운스 ms (기본값: 200)
    onSelect: (item) => {}              // 항목 선택 콜백 (생략 가능)
});
```

**필요한 HTML 구조:**
```html
<div class="autocomplete-wrap">
    <input type="text" id="bankCdText" autocomplete="off">
    <div id="bankBalloon" class="autocomplete-balloon"></div>
</div>
```

**CSS:** `defaultLayout.html` 공통 스타일에 포함 (`.autocomplete-wrap`, `.autocomplete-balloon`, `.autocomplete-item`)

**반환값:** `{ close(), select(code, name) }` 컨트롤러 객체

### 6-2. `CommonUtils.initCombos` — 공통 코드 콤보박스 자동 채움

`data-code-type` 속성이 있는 `<select>` 에 자동으로 공통코드를 로드.

```html
<select id="deptSelect" class="common-combo" data-code-type="dept">
    <option value="">전체</option>
</select>
```

```javascript
// DOMContentLoaded 시 자동 실행됨. 수동 호출도 가능:
CommonUtils.initCombos();
```

## 2. 공통 그리드 — `TuiPageBuilder`

> **위치:** `src/main/resources/static/js/common/tui-page-builder.js`

모든 목록 화면은 TuiPageBuilder를 통해 TUI Grid + 페이징을 초기화한다.

```javascript
const pageBuilder = new TuiPageBuilder({
    el:           'grid',                  // 그리드 컨테이너 id
    apiUrl:       '/basic/currency/data',  // 데이터 API
    searchInputs: ['baseDt', 'currencyCd'],// 검색 input id 목록
    rowHeaders:   ['rowNum'],
    columns: [
        { header: '기준일자', name: 'baseDt', width: 110, align: 'center' },
        // ...
    ]
});
```

**Row hover 음영:** `defaultLayout.html` 공통 스타일에서 `.tui-grid-row-hover` CSS로 전역 적용됨.

## 3. 공통 검색조건 콤보 — `/api/common-code/{type}`

새로운 코드성 콤보가 필요할 때 `CommonCodeService`에 케이스를 추가한다.

```java
// CommonCodeService.java
if ("bank".equalsIgnoreCase(codeType)) {
    return commonCodeMapper.selectBanksByKeyword(keyword);
}
```

```javascript
// 콤보 전체 로드
fetch('/api/common-code/bank')

// 자동완성 검색
fetch('/api/common-code/bank?keyword=KE')
```

**현재 등록된 코드 타입:**

| 타입 | API | 설명 |
|------|-----|------|
| `dept` | `/api/common-code/dept` | TB_DEPT 부서 전체 |
| `messages` | `/api/common-code/messages?deptId=` | 부서별 메세지 (캐스케이드) |
| `bank` | `/api/common-code/bank?keyword=` | TB_BANK 은행코드 (Typeahead 지원) |
