## 입력 컴포넌트 유형 범례

| 표기 | 컴포넌트 |
|------|----------|
| `(콤보)` | Select Box (드롭다운) |
| `(라디오: A / B / C)` | Radio Button Group |
| `(년월일)` | Date Picker (일자 단위) |
| `(년월일시분)` | DateTime Picker (분 단위) |
| `(년월일 단일)` | Date Picker, 단일 날짜 |
| 표기 없음 | Text Input |
| `미정의` | 원본 데이터 미제공 |
